# ADR 0002：参考图标定的三维手柄运动

- 状态：已接受，实施中
- 日期：2026-11-23
- 范围：手柄展示层的摇杆运动、Extreme 3D Pro 立体运动、冰原狼 4 清晰度；不改变 HID 映射、机器人输出或安全门。

## 问题与约束

现行展示把完整底图上的原摇杆帽用邻近像素覆盖，再裁剪一个圆形摇杆帽平移。它消除了重影，却没有轴心、杆身、厚度、动态遮挡和透视变化；修补区域还会产生可见的重复纹理。用户录屏明确要求 F310、冰原狼 4、Extreme 3D Pro、PS4、PS5、Xbox Series 全部解决，不接受继续修补 PNG 或锐化放大。

用户已确认按“普通手柄真实分层运动、飞行摇杆真正三维运动”的方向完整实施。不得借视觉重写改变已经验证的输入方向、按键和扳机映射。

## 备选方案

1. **原厂外观 + 三维摇杆，飞行摇杆完整三维装配（采用）**：保留产品图片的主体，按已标定井口和摇杆帽构造几何、纹理、遮挡与阴影。能保留各款辨识度，并把真实感动画集中在运动部件。
2. 全部手柄从零制作完整三维模型：运动统一，但在缺少原厂 CAD 的情况下容易失去原厂外观，工作量与失真风险都更大，不采用。
3. 继续二维裁剪、透视变换和修图：不能解决固定纹理、遮挡和杆身缺失，不采用。

## 设计

### 共用运动模型

新增纯 Swift 运动模型，把归一化输入映射为摇杆绕井口轴心的姿态。井口、帽顶尺寸沿用各款原生图片的标定矩形；中立姿态严格回中，异常输入安全回中，斜向输入受井口边界约束。投影位移、倾角和轴心之间使用显式三角变换，不能再对整个摇杆图片只做 `offset`。

轴心的显示长度以对应摇杆帽的实测半径为单位；全行程投影仍受原井口与帽顶差值约束。这个模型是用于显示的标定几何，不宣称是厂商未公开的机械尺寸。

### 普通手柄

使用 macOS 自带 SceneKit，无新增第三方依赖。每个摇杆包含井口、杆身、带侧面的凹面帽顶和接触阴影。帽顶 UV 保留对应产品的原始纹理，不再以圆形蒙版平移整张图片。按下描边跟随三维帽顶姿态。

原图只遮除原摇杆所在区域，孔后由三维井口填充；不再把邻近像素拉伸进摇杆区域。其余主体像素保持不变，原按键高亮、扳机深度和可访问性标签继续复用。

### Extreme 3D Pro

使用 SceneKit 节点装配固定底座、球关节、杆身和手柄。轮廓与枢轴来自现有 1510×1112 分层参考图；使用有厚度的几何、表面纹理和光照，而不是对 PNG 做 `rotation3DEffect`。前后左右绕固定球关节运动，Z 轴只扭转手柄，底座保持静止。保持现有 7° 前后/左右与 16° 扭转显示幅度，不另选新的动画参数。

### 冰原狼 4

Space Station 4.2.3.1 没有三维模型，fp4 的最大正视 PNG 为 492×341。不得把它放大后称为高清。优先寻找原厂更高清素材；若无，则按原始透明轮廓和控件位置重建矢量/几何资产，以高分辨率重新渲染默认白色款。重建素材必须明确标为重建设备图，不能冒充官方照片。

### 错误处理与性能

资源或几何生成失败时明确报告，不能静默退回假贴图。视图只在输入状态改变时更新，不启动常驻渲染定时器；几何和纹理缓存，输入提取与机器人输出分离。场景必须能离屏渲染供自动化检查。

## 验收

- 纯数学测试：中立、方向、斜向、非有限输入、固定轴心和井口边界。
- 实际渲染：每款中立、上、下、左、右、斜向和按下状态；无第二帽顶、无平移贴片、无补洞纹理，轴心不漂移。
- 飞行摇杆：前后左右与扭转时真实节点变换，底座不动，枢轴不漂移，保持俯视。
- 冰原狼：正视、默认白色、轮廓干净，摇杆区域无修补痕迹，清晰度来自重建几何而非插值放大。
- 现有 HID 映射、扳机范围、按键、搜索和自动识别回归全部保留。
- 最终合并树运行核心、UI、打包版 E2E、Sparkle 更新测试，并在真实安装版逐款查看。实物逐项操作仍须用户手动配合，不能用模拟渲染替代。
