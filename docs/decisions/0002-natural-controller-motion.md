# ADR 0002：参考图标定的三维手柄运动

- 状态：已接受，已实施
- 日期：2026-11-23
- 范围：手柄展示层的摇杆运动、Extreme 3D Pro 立体运动、冰原狼 4 清晰度；不改变 HID 映射、机器人输出或安全门。

## 问题与约束

现行展示把完整底图上的原摇杆帽用邻近像素覆盖，再裁剪一个圆形摇杆帽平移。它消除了重影，却没有轴心、杆身、厚度、动态遮挡和透视变化；修补区域还会产生可见的重复纹理。用户录屏明确要求 F310、冰原狼 4、Extreme 3D Pro、PS4、PS5、Xbox Series 全部解决，不接受继续修补 PNG 或锐化放大。

用户已确认按“普通手柄真实分层运动、飞行摇杆真正三维运动”的方向完整实施。不得借视觉重写改变已经验证的输入方向、按键和扳机映射。

## 备选方案

1. **原厂外观 + 三维摇杆，飞行摇杆完整三维装配（采用）**：保留产品图片的主体，按已标定井口和摇杆帽构造几何、纹理、遮挡与阴影。能保留各款辨识度，并把真实感动画集中在运动部件。
2. 全部手柄从零制作完整三维模型：运动统一，但在缺少原厂 CAD 的情况下容易失去原厂外观，工作量与失真风险都更大，不采用。
3. 继续二维裁剪、透视变换和修图：不能解决固定纹理、遮挡和杆身缺失，不采用。

## 设计

### 共用运动模型

新增纯 Swift 运动模型，把归一化输入映射为摇杆绕自身轴心的姿态。图片被当作从正前方偏上 20° 拍摄的正交照片：转动轴心位于帽顶中心的前下方（靠使用者一侧），摇杆静止时背离使用者后仰 20°，使帽顶轮廓与原图一致。俯角在所有手柄和左右摇杆之间统一，不随帽顶轮廓变化。

满量程偏转固定为真实摇杆模块的机械极限 20°，与井口、帽顶的标定差值无关。第一版曾用井帽差值反推倾角（`asin(行程 / 帽顶半径)`），各款算出 17°–50°，叠加基础角后冰原狼 4 接近 71°，摇杆被放倒成扁盘并露出杆身；数值测试全部通过，直到在原始分辨率下看近景图才暴露。

朝远离使用者方向推时倾角叠加，顶面变扁、前侧壁变高；朝使用者方向推时摇杆回正，顶面变圆。帽顶行程小于一个帽顶半径，斜向输入按圆形量程归一化，中立严格回中，异常输入安全回中。这个模型是用于显示的标定几何，不宣称是厂商未公开的机械尺寸。

### 普通手柄

使用 macOS 自带 SceneKit，无新增第三方依赖。每个摇杆包含井口、杆身、带侧面的帽顶和接触阴影。帽顶 UV 保留对应产品的原始纹理，贴图正立（图片首行对应帽顶上沿）。原图轮廓偏扁或偏高的帽顶用椭圆截面贴合原图轮廓。侧壁与杆身颜色取帽顶下缘最暗的四分之一像素，即照片里真正可见的侧壁，而不是帽顶顶面纹理。

几何按显示尺寸构建，纹理始终按原图像素裁剪，两者不得混用单位；纹理尺寸不随显示缩放变化。按下描边跟随三维帽顶姿态。

原图只遮除原摇杆所在区域，孔后由三维井口填充；不再把邻近像素拉伸进摇杆区域。其余主体像素保持不变，原按键高亮、扳机深度和可访问性标签继续复用。F310 两个帽顶的标定框按原图亮度剖面重新量定：纵向 306.5–405，横向中心分别为 278.2 和 475.2；原右帽顶标定框偏左 2.7 像素，会在中立时露出暗弧。

### Extreme 3D Pro

使用 SceneKit 节点装配固定底座、球关节、杆身和手柄。原图 alpha 转为逐像素实体网格，并生成真实侧壁与倒角，避免 `SCNShape` 在复杂孔洞上生成空几何。球关节中心由原图座圈连续等宽轮廓（y=700、710、720，中心 x=765.5）标定为 `(765.5, 710)`，不再沿用旧 `(797, 662)`。前后左右绕固定球关节运动，Z 轴只扭转手柄，底座保持静止。保持现有 7° 前后/左右与 16° 扭转显示幅度，不另选新的动画参数。透明可访问性区域随真实节点位置更新，固定底座区域不随手柄移动。

### 冰原狼 4

Space Station 4.2.3.1 没有三维模型，fp4 的最大正视 PNG 为 492×341。不得把它放大后称为高清。最终保留 `direwolf4-reference.png` 作为官方参考，`direwolf4.png` 为 1968×1364 的矢量/几何重建图，并生成独立的左右帽顶和井口资源。`scripts/render-direwolf4.swift` 以原始透明轮廓、Logo 矢量、颜色采样和几何渐变重复生成，重复运行哈希一致。重建素材明确标为重建设备图，不能冒充官方照片。

### 错误处理与性能

资源或几何生成失败时明确报告，不能静默退回假贴图。视图只在输入状态改变时更新，不启动常驻渲染定时器；几何和纹理缓存，输入提取与机器人输出分离。场景必须能离屏渲染供自动化检查。

## 验收

- 纯数学测试：中立、方向、斜向、非有限输入、轴心位于帽顶前下方的井口内、20° 偏转上限、帽顶半径内的行程和统一的俯角。
- 实际渲染：每款中立、上、下、左、右、斜向和按下状态；无第二帽顶、无平移贴片、无补洞纹理，运动只改变井口内的像素。帽顶纹理正立，并在 1 倍和 3 倍显示下保持一致；条纹帽顶测试对颠倒贴图必须失败。
- 渲染验收必须在原始分辨率下放大查看。缩小预览会掩盖过度旋转、半透明帽顶和标定偏移。
- 飞行摇杆：前后左右与扭转时真实节点变换，底座不动，枢轴不漂移，保持俯视。
- 冰原狼：正视、默认白色、轮廓干净，摇杆区域无修补痕迹，清晰度来自重建几何而非插值放大。
- 现有 HID 映射、扳机范围、按键、搜索和自动识别回归全部保留。
- 最终合并树运行核心、UI、打包版 E2E、Sparkle 更新测试，并在真实安装版逐款查看。实物逐项操作仍须用户手动配合，不能用模拟渲染替代。
